# 🍝 Massa Mia - Restaurante Italiano

O restaurante **Massa Mia** foi um projeto inicialmente criado em grupo para o TCC do ensino médio integrado ao técnico em administração, onde é apenas uma empresa do ramo culinário. <br>
Agora na área de tecnologia aprovetei o TCC passado para transformá-lo em site e melhorar minhas habilidades.

---

## Sobre Projeto

> **Status do Projeto:** 🚀 Em andamento

Este projeto é de um sistema para um restaurante italiano, inicialmente tendo apenas a página inicial e seu respectivo cardápio, e outra funcionalidades que ainda serão concluídas. <br>
Foi construído primeiramente pensado na experiência mobile e sendo adaptado para telas maiores. <br>
Depois destas implementações foi criado o backend para inserir os produtos integrado com o banco de dados, sendo uma funcionalidade que apenas o administrador poderá executar.

## Como executar o projeto

### Pré-requisitos
Você só precisa de um navegador moderno e do Git instalado.

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/yumisszx/restaurant-massa-mia.git](https://github.com/yumisszx/restaurant-massa-mia.git)
   ```

2. **Acesse a pasta:**
    ```bash
    cd restaurant-massa-mia

    npm install

    npm run dev
    ```

3. **Abra o arquivo principal:** <br>
Depois de iniciado visualize no browser o projeto.
